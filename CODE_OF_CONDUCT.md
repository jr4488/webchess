# WebChess community code of conduct

## Our standard

WebChess depends on technically precise disagreement. Critique claims, code, evidence, and reasoning directly; treat people with respect.

Examples of constructive participation include:

- making claims proportional to the available evidence;
- distinguishing observation, interpretation, and uncertainty;
- providing reproducible examples;
- welcoming correction and competing explanations;
- respecting privacy and credential boundaries.

Unacceptable behavior includes harassment, threats, discrimination, sexualized conduct, deliberate disruption, publishing private information, sharing credentials, or claiming that WebChess predicts events, certifies truth, or replaces professional judgment.

## Enforcement

Project maintainers may edit or remove contributions and may temporarily or
permanently restrict participation when conduct is inconsistent with this
standard.

For disruptive GitHub content, use the content menu's **Report content**
control. It can report the content to repository administrators or to GitHub
Support without publishing a new allegation. GitHub documents the process in
[Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

The project's private vulnerability-reporting flow is only for security
vulnerabilities, not conduct complaints. The project does not currently
publish a separate private conduct email. Do not put sensitive personal
information in a public issue or Discussion.

## Scope

This standard applies in repository spaces and when an individual officially represents WebChess elsewhere.

This policy is informed by Contributor Covenant 2.1 and adapted to the project's research and security boundaries.
